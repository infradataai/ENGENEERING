# Projeto Geométrico

Materiais de apoio para **projeto geométrico de vias**: traçado em planta e perfil,
curvas horizontais e de transição, curvas verticais, superelevação, superlargura,
distâncias de visibilidade e seção transversal.

> Conteúdo **didático e preliminar**, voltado ao aprendizado. Confira sempre com as normas
> vigentes (DNIT, AASHTO) e com um engenheiro responsável.
